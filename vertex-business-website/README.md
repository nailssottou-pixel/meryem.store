# Vertex Studio business website

Responsive single-page business website with CSS 3D animations, service sections, a contact email draft, and a login/sign-up interface demo.

## Publish with GitHub Pages

1. Open the repository Settings.
2. Select Pages.
3. Under Build and deployment, select **Deploy from a branch**.
4. Choose branch `main` and folder `/(root)`, then Save.
5. After GitHub finishes publishing, open `https://nailssottou-pixel.github.io/meryem.store/vertex-business-website/`.

If Pages is already enabled for this repository, the subfolder will be included in the published site.

## Important

The login and sign-up panel is a visual demo, not real authentication. Do not enter real passwords. To enable real accounts, connect a secure authentication provider. The contact form opens the visitor's email app and currently uses the placeholder `hello@example.com`; replace it with your actual business email before launch.
