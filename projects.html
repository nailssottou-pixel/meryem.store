🔧 Fix My Bike — High-Potential MVP

Why This Concept Works

  1. Specific Pain Point: Cyclists face repeated diagnosis paralysis — bike shops are expensive, slow, and beginner-unfriendly.
  2. Recurring Revenue Potential: Free diagnosis → Premium video guides + maintenance tracking + mechanic chat ($5–8/mo).
  3. Built-In Moat: Content library (repair guides), user bike profiles, community trust. Hard to disrupt once you own "bike health."
  4. Multiple Revenue Streams: Freemium SaaS, affiliate commissions (parts links), shop partnerships (referral fees).
  5. Technical Feasibility: Computer vision for photo diagnosis, LLM-generated content, PostgreSQL for profiles. No bleeding-edge tech required.

Tech Stack

Frontend: React 18 + TypeScript, Tailwind CSS, React Router, Zustand (state management)

Backend: Node.js + Express, PostgreSQL, Redis (caching + job queue)

AI/Vision: OpenAI Vision API (photo diagnosis), Claude (repair guide generation)

Cloud: AWS (S3 for images, Lambda for async jobs) or Firebase (faster MVP)

Auth: Auth0 or Firebase Auth (OAuth for social login)

Payments: Stripe (subscriptions + affiliate tracking)

Search: Elasticsearch or Typesense (repair guides + shop directory)

MVP Features (Phase 1)

  • Diagnosis Engine: Upload photo/video → OpenAI Vision API → structured diagnosis with confidence score
  • Symptom Picker: Guided form for sound/feel/visual symptoms → narrow diagnosis
  • Bike Profile: Store bike type (road, MTB, hybrid), brand, groupset, year. Save multiple bikes.
  • Repair Guides: Pre-written + AI-generated step-by-step instructions with image references. Text only for MVP.
  • Safety Flag: Dangerous issues (frame cracks, brake failure) → "Stop — see a mechanic" banner
  • Maintenance Log: Track repairs, parts replacements. Simple reminder system (time-based, not mileage yet)
  • Shop Directory: Basic map + shop search. No booking integration yet (Phase 2)

Revenue Model (Post-MVP)

  • Freemium SaaS: Free diagnosis + text guides. Pro ($7/mo) for video walkthroughs, mechanic chat, ad-free.
  • Affiliate Revenue: Links to parts (chains, brake pads, cables). Estimate 1–3% click-through, $5–20 per conversion.
  • Shop Partnerships: Local bike shops pay per qualified referral ($10–25 per booking). Refer users, track completion.
  • B2B Content Licensing: Repair content sold to bike manufacturers, media, insurance companies (future).

Risks & Mitigations

  • Vision API Accuracy: Photo diagnosis may misidentify issues, leading to incorrect repairs.
    Mitigation: Always show confidence score, provide multiple hypotheses, safety warnings, and escalation to mechanic chat for low-confidence cases.
  • Content at Scale: Creating 500+ repair guides is massive lift.
    Mitigation: LLM-generate base content from templates, have community review/improve, prioritize top 50 repairs first.
  • Shop Directory Accuracy: Bike shop data (hours, pricing) changes frequently.
    Mitigation: Use Google Maps API for authoritative source, user-submitted corrections, import from BikeLingo.
  • User Liability: User follows bad repair guide, bike breaks.
    Mitigation: Clear disclaimer in ToS, safety flags for critical repairs, liability insurance.

🏆 Bill of Rights — The Selected MVP

Why This Wins

  1. Universal Pain: Average US household loses $240–$420/year to forgotten subscriptions.
  2. Built-In Moat: Cancellation is intentionally tedious by design. Your edge: AI-generated cancellation emails, scripts, phone walkthroughs.
  3. Multiple Revenue Streams: Freemium (scan), Pro ($9.99/mo), B2B integrations ($500+/mo), affiliate commissions.
  4. Technical Simplicity: Plaid API + LLM prompts + Email integration. No blockchain, no ML training required.
  5. Time to Market: MVP in 8–12 weeks, revenue in 3–4 months.

MVP Features (Phase 1)

  • Connect Bank: Plaid OAuth → scan recurring charges
  • Email Integration: Gmail/Outlook → parse recurring receipts
  • Smart Categorization: Spotify, Netflix, Adobe, etc.
  • Dashboard: List all subscriptions + monthly cost + savings potential
  • Cancellation Engine: LLM generates personalized cancellation email
  • Send & Track: Email delivery via Sendgrid, track success

Risk Management

  • API Brittleness: Cancellation pages change → scripts break.
    Mitigation: Crowdsource updates, AI adapts on failure, multiple fallback paths.
  • Legal Gray Zone: Sending emails on behalf of user.
    Mitigation: Clear ToS, user must explicitly authorize each email, preserve audit trail.
  • Service Updates: Plaid/email API rates/features change.
    Mitigation: Use multiple providers, negotiate SLAs early, monitor competitor APIs.
